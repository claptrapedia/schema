# Claptrapedia Schema

The shared data contracts for the Claptrapedia ecosystem, defined with [Zod](https://zod.dev) and exported as inferred TypeScript types.

Provides consistent validation and type safety across the compiler, app and other tools, with support for multiple Borderlands games and item types.
